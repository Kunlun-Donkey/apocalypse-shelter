# 引导语音风格样本 manifest (试听选型用)

> 用途: 4 个候选风格试听对比, **同一段台词, 只换音色**。选定风格后按 AGENTS.md §13.8
> 重写完整台词表并批量生成正式 VO 文件; 本目录为选型临时件, 定稿后可删或转正。
> 生成方式: 云端 MiMo TTS (`xiaomi/mimo-v2.5-tts`), user 消息放音色指令, assistant 消息放台词。

## 试听台词 (4 个样本完全相同)

```text
庇护所核心，绑定完成。评级：简易庇护所。……生存率，百分之三点七。但你还在。这就够了。
```

## 音频规格

- WAV (RIFF pcm_s16le), 24000 Hz, 单声道 — TTS 原生输出
- 正式 VO 定稿后按 AGENTS.md §13.6 转 44.1kHz; 响度统一峰值 -6dB
